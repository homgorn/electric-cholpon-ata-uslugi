## 1. Как работает сайт (30 сек)
- **Не CMS**. Нет WordPress, нет админки в традиционном смысле.
- **Источник правды** = файлы в `data/*.json`. Правите их → `npm run build` → деплой.
- **Генератор** (`scripts/generate-content.mjs`) читает JSON и генерирует 370+ `.md` страниц с одинаковой структурой (ответ в первых 100 символах, таблица цен, FAQ, цитаты, CTA).
- **Каждая услуга** генерируется по шаблону с `seed = hash(slug)` — соседние гео-страницы различаются на 40–60% (анти-дорвей).
- **БД SQLite** (`data/db.sqlite`) = карта всех страниц с ценами, типами, FAQ. Можно запросить SQL (`SELECT * FROM pages WHERE type='geo'`).
- **Экспорт CSV** (`npm run export`) готов для загрузки в карты/маркетплейсы/CRM.

## 2. Как редактировать (без кода, через GitHub)

### A. Цены / описание услуги
1. Открой https://github.com/homgorn/electric-cholpon-ata-uslugi в браузере
2. Найди `data/services/provodka.json` (или любую категорию) → ✏️ Карандаш → измени `price_min` / `price_max`
3. Commit Changes (сообщение: «цены: замена розетки»)
4. GitHub Actions (`deploy.yml`) задеплоит автоматически через 2 мин → сайт обновится
5. Локально для проверки: `npm run gen` (только генерация) или `npm run build` (полная сборка)

### B. Контакты (в ОДНОМ месте)
1. `data/site.json` → меняешь `phone_display`, `whatsapp`, `telegram`, `email`
2. `npm run gen` — все 384 страницы получают новые контакты в футере, префиллах и CTA

### C. Новое село в географию
1. `data/locations.json` → добавь объект ОБЯЗАТЕЛЬНО с `pre` (склонение):
```json
{"slug":"kokshetau","name":"Кокшетау","pre":"Кокшетау","distance_km":20,"travel_fee":300,"zone":"mid","facts":["Новый район"]}
```
⚠️ Без `pre` страницы будут с ошибками склонения («в Кокшетау» вместо «в Кокшетау» — но `pre` решает всё автоматически).
2. Для 7 приоритетных услуг (`geo_priority: true`) автоматически появится 7 новых страниц.

### D. Новая услуга (подробно в §3)
1. `data/services/{категория}.json` → добавь строку с обязательными полями:
```json
{"slug":"ustanovka-rozetki-vlagozashchitnnoy","name":"Установка влагозащищённой розетки","name_gen":"установки влагозащищённой розетки","category":"rozetki-vyklyuchateli","price_min":700,"price_max":1500,"unit":"точка","time":"40–80 минут","tags":["rozetki","dom-dacha"],"geo_priority":false,"includes":["...","...","...","..."],"steps":["...","...","...","..."],"symptoms":["...","...","...","..."]}
```
⚠️ `name_gen` = родительный падеж («установки влагозащищённой розетки»). Без него заголовки будут с ошибками.
⚠️ `geo_priority: true` = автоматически генерируются страницы для всех 32 сёл.
2. `npm run gen` — страница готова.

## 4. Как заполнить каталог мастеров

`data/masters.json` содержит каркас с `status: "todo"` (скрыто) или `"active"` (показано на `/mastera/`).

Пример заполнения для одного мастера:
```json
{"id":1,"name":"Александр Алексеев","status":"active","phone":"+996555555555","whatsapp":"https://wa.me/996555555555","telegram":"https://t.me/aleksandr_electric","rating":4.9,"jobs_done":109,"experience_years":11,"specialties":["замена-розетки","монтаж-проводки","сборка-щитков"],"areas":["Чолпон-Ата","Бостери","Тамчы"],"bio":"Старший электрик с опытом 11 лет, более 2000 выполненных заказов. Специализация: полный спектр электромонтажа."}
```
⚠️ Поля `specialties` и `areas` — массивы **slug** из `data/services/*.json` и `data/locations.json`. Без них карточка не покажет зоны и услуги.

После заполнения: `npm run db` → `npm run export` → `npm run build`.

## 5. Как заменить заглушку отзывов на реальные (v1.2)

Сейчас `AggregateRating` (4.8/127) и 2 отзыва в коде — заглушки (`docs/ADMIN-GUIDE.md` §Отзывы). После первых 10+ реальных клиентов:

1. **Собери данные**: форма на `/mastera/` или через Telegram-бот или `docs/research/fetched/`
2. **Структура `data/reviews.json`:**
```json
{"author":"Аскар","rating":5,"text":"...","date":"2026-08-25","verified":true,"location":"bosteri","service":"zamena-rozetki"}
```
3. **Обнови `jsonld.ts`**: замени массивы `aggregateRatingSchema` и `reviewsSchema` на данные из `reviews.json`
4. **Пересобери**: `npm run build` → новые данные в HTML
5. **Удалить заглушки** из `src/pages/uslugi/[cat]/[svc].astro` (строки 34–52 в текущей сборке) — заменить на чтение из `data/reviews.json`

## 6. Блог: программная машина под нишу (v1.2 уже готов)

**Стратегия не «статьи ради статей»**, а длинный хвост под нишу:

- **Столпы** (`RESEARCH-services.md`): 85 услуг → статьи типа «Замена проводки в доме — этапы, сроки, цены» (под ключ)
- **Кластеры** (`RESEARCH-competitors.md`): проблемные запросы («выбивает автомат»), сезонные («подготовка пансионата»), гео-обзоры («электрика в Ананьево»)
- **Товарные статьи** (`docs/BLUEPRINT.md` §6): каталог электрики, статьи типа «Кабель ВВГнг 3х2.5 — как выбрать» с `Product` JSON-LD

**Пайплайн:**
```bash
npm run fetch-blog     # фетчит raw HTML → docs/research/fetched/{slug}/
npm run gen            # черновики с status: draft не публикуются
# Ручной рерайт: убираешь status: draft из frontmatter статьи
npm run build           # статья публикуется
```

**SEO-проверка каждой статьи** (`validate.mjs`):
- `lead` содержит цифру в первых 100 символах
- `body` ≥ 3000 символов (проверено на 5 seed-статьях — среднее 5035)
- FAQ 4+ (`faq:` массив в frontmatter)
- Цитаты (ключи из `citations.json` в массиве `citations`)
- Article JSON-LD (`datePublished`, `keywords`, `author`, `publisher/logo`)
- Перелинковка на категорию и главную (через тело статьи и футер)
