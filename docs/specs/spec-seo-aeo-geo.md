# Spec: SEO/AEO/GEO стандарты страниц

## Title (≤65 симв.)
Формат услуги: `{Услуга} в Чолпон-Ате — цена от {min} сом | Электрик Иссык-Куль`
Формат гео: `{Услуга} в {НП} — от {min} сом, выезд {fee} сом`
Ключ — в первых 40 символах.

## Description (120–165 симв.)
`{Услуга} в {НП}: от {min} до {max} сом, {time}. Выезд {fee} сом. WhatsApp с фото — ответ за 5 минут.`

## H1
`{Услуга} в {НП} — цена от {min} сом` (гео) / `{Услуга} в Чолпон-Ате — цены от {min} сом`

## Лид (первые 100 символов после H1)
Шаблон: `{Услуга} в {НП} стоит от {min} до {max} сом за {unit}. Мастер приедет за {eta}.`
— ровно ответ на запрос пользователя. Валидатор проверяет наличие цифры ≤100 симв.

## Структура H2–H4
```
H1 {Услуга} в {НП}
лид-ответ
H2 Сколько стоит {услуга}          → таблица цен + примечание о выезде
H2 Что входит в работу             → список includes
H2 Как проходит работа             → нумерованный steps
H2 Когда нужно вызывать мастера    → symptoms list
H2 Особенности в {НП}              → локальный блок (гео-страницы)
H2 Почему выбирают нас             → 5 пунктов
H2 Частые вопросы                  → FAQ 4–6 (+FAQPage JSON-LD)
H2 Источники                       → цитаты
CTA-блок
```

## JSON-LD (все страницы услуг)
```json

  {"@type":"Service","name":"…","areaServed":{"@type":"Place","name":"Чолпон-Ата"},
   "provider":{"@id":"#electrician"},"offers":{"@type":"Offer",

   "priceCurrency":"KGS"}}},
  {"@type":"FAQPage","mainEntity":[{"@type":"Question","name":"…",
    "acceptedAnswer":{"@type":"Answer","text":"…"}}]},
  {"@type":"Electrician","@id":"#electrician","name":"Электрик Чолпон-Ата",
   "telephone":"+7996555707267","areaServed":[…],"url":"…"},
  {"@type":"BreadcrumbList",…}
]}
```
Блог: `BlogPosting` + author + datePublished.

## AEO/GEO-инфраструктура
- `/robots.txt`: Allow всем, явные User-agent: GPTBot, ClaudeBot, Claude-Web, PerplexityBot,
  Google-Extended, CCBot, Bytespider → Allow; Sitemap: полный URL
- `/llms.txt` (llmstxt.org): заголовок, блок One-liner, разделы H2 со ссылками
- `/llms-full.txt`: полный markdown всех страниц (для RAG-индексации)
- `/md/{путь}.md`: чистый markdown каждой страницы (frontmatter + тело)

## Перелинковка
- Услуга → категория, 3–5 соседних услуг, локация-хаб
- Гео-страница → услуга-ядро, локация-хаб, 3 соседних гео (та же услуга рядом НП)
- Локация-хаб → все 6 гео-услуг этого НП + топ-10 ядровых услуг
- Хлебные крошки везде + BreadcrumbList

## Запрещено
- Дубли title/H1 между страницами (валидатор)
- Каннибализация: гео-страница не таргетит «чолпон ата» без НП
- Скрытый текст, дорвейные редиректы, автогенерированный бессмысленный текст
