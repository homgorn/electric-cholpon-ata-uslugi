# Constitution (Spec Kit): неизменяемые принципы

1. **Ответ прежде продажи.** Первые 100 символов страницы отвечают на запрос с цифрой.
2. **Данные — единственный источник правды.** Контакты, цены, локации меняются только в data/*.json.
3. **Каждая страница = лендинг.** CTA WhatsApp+Telegram, префилл текста услуги.
4. **≥3000 символов** полезного текста на страницу услуг; без воды.
5. **Цитаты реальны.** Только источники из data/citations.json; нет факта — нет ссылки.
6. **Валидатор — гейт деплоя.** build падает при нарушении конституции.
7. **Детерминизм.** Один slug → один и тот же контент при пересборке (seeded random).
8. **Экспортируемость.** База всегда выгружается в CSV/JSON для будущих сервисов.
9. **Markdown-first.** HTML-страница и её .md-версия генерируются из одного источника.
10. **TODO не забываются.** Всё незакрытое живёт в docs/roadmap.md со статусом.
